# English Teacher Landing

A modern landing page for an English language teacher built with React, TypeScript, and Tailwind CSS.

The project is designed for adult learners and serves as a platform to showcase teaching services, present the instructor's methodology, and collect trial lesson inquiries.

## Tech Stack
React
TypeScript
Vite
Tailwind CSS
Framer Motion
Lucide React

## Getting Started

Install dependencies
```bash
npm install
```

Run development server
```bash
npm run dev
```

Application will be available at:
http://localhost:5173


## Build

Create production build:

```bash
npm run build
```
